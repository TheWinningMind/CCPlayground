# New material for the AP Biology Unit 2 study guide

Upload folders and files here. Folder structure is kept, so you can drag in
whole folders from your computer.

How: on github.com, open this folder on the `claude/happy-hopper-8rl1se` branch,
click **Add file → Upload files**, drag your folders in, then **Commit changes**.

Limits: each file must be under 25 MB, and about 100 files per upload.
For more, upload in several rounds.
